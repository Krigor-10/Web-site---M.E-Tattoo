# Web Site - M.E. Tattoo 🎨✒️

Este é um projeto de site institucional (Landing Page) desenvolvido para a tatuadora **Maria Eduarda (M.E. Tattoo)**, especialista em traços finos (Fineline) e Lettering. 
O objetivo do site é apresentar o portfólio da artista, fornecer informações sobre seu estilo de trabalho e facilitar o contato para orçamentos.

## 🚀 Demonstração

O projeto está disponível online através do GitHub Pages:
https://krigor-10.github.io/Web-site---M.E-Tattoo/

## 🛠️ Tecnologias Utilizadas

O site foi construído utilizando tecnologias web fundamentais para garantir leveza e performance:

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização, layout responsivo e design moderno.
- **Google Fonts**: Tipografia personalizada para uma estética elegante.
- **Font Awesome**: Ícones para redes sociais e interface.

## 📱 Funcionalidades

- **Design Responsivo**: Adaptado para visualização em dispositivos móveis, tablets e desktops.
- **Seção Sobre**: Breve introdução sobre a trajetória e especialidade da artista.
- **Galeria de Portfólio**: Exibição de trabalhos realizados com foco em detalhes.
- **Chamada para Ação (CTA)**: Botões estratégicos para agendamentos e visualização de trabalhos.
- **Integração com Redes Sociais**: Links diretos para WhatsApp e Instagram.
